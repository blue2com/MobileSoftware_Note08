# 🐙 Git Clone 후 프로젝트 적용 가이드 (학생용 안내)

학생들이 강사님의 GitHub에서 소스 코드를 `git clone` 받은 후, 자신들의 안드로이드 스튜디오 환경에서 어떻게 프로젝트를 열고 실습을 진행하는지 안내하는 가이드입니다. 
수업 시작 시 학생들에게 이 순서대로 안내하시면 됩니다.

---

## 1. 프로젝트 가져오기 (Git Clone)

안드로이드 스튜디오를 처음 켰을 때 나오는 시작 화면(Welcome to Android Studio)에서 진행합니다.

1. 시작 화면에서 **`Get from VCS`** (버전 관리 시스템에서 가져오기) 버튼을 클릭합니다.
2. `URL` 입력 칸에 강사님이 제공한 **GitHub 레포지토리 주소**(예: `https://github.com/강사님계정/MobileProject.git`)를 붙여넣습니다.
3. `Directory`에 프로젝트를 저장할 폴더를 확인하고 **`Clone`** 버튼을 클릭합니다.

---

## 2. 프로젝트 열기 및 싱크 (Gradle Sync)

Clone이 완료되면 안드로이드 스튜디오가 자동으로 프로젝트를 엽니다. 이 때 가장 중요한 작업이 진행됩니다.

1. 프로젝트가 열리면, 안드로이드 스튜디오 하단 또는 상단에 로딩 바가 돌아가면서 **Gradle Sync(동기화)** 작업이 시작됩니다.
   * *이 과정은 필요한 라이브러리(Room, Hilt 등)를 인터넷에서 다운로드하는 과정이므로 몇 분 정도 걸릴 수 있습니다.*
2. 만약 "Trust Project?" 같은 보안 경고 창이 뜬다면 **`Trust Project`**를 클릭합니다.
3. Sync가 완료되면 화면 왼쪽 `Project` 뷰에서 폴더 구조(`app`, `note08` 등)가 정상적으로 표시되는지 확인합니다.

---

## 3. 특정 모듈 (note08) 실행하기

이 프로젝트는 여러 모듈(note07, note08 등)로 구성되어 있습니다. 오늘 실습할 `note08` 모듈을 실행하는 방법입니다.

1. 안드로이드 스튜디오 상단 중앙의 **실행 구성(Run Configuration) 드롭다운 메뉴**를 클릭합니다. (보통 기본적으로 `app`으로 되어 있습니다.)
2. 목록에서 **`note08`** 을 선택합니다.
3. 옆에 있는 **재생 버튼(Run, ▶️)** 을 눌러 에뮬레이터나 연결된 스마트폰에서 앱을 실행합니다.

---

## 4. (선택 사항) 내 개인 GitHub에 연결해서 과제 제출하기

학생들이 과제를 수행한 후 자신의 GitHub에 코드를 올려야 한다면 다음과 같이 안내합니다.

1. 상단 메뉴에서 **`Git` -> `Manage Remotes...`** 를 클릭합니다.
2. 기존에 등록된 강사님의 주소(`origin`)를 삭제(`-` 버튼)하거나 이름을 바꿉니다.
3. 새로운 저장소 주소(`+` 버튼)를 추가하고, 학생 본인이 새로 만든 GitHub 레포지토리 URL을 넣습니다.
4. 이후 평소처럼 **Commit** 및 **Push**를 진행하면 학생 본인의 저장소로 코드가 올라갑니다.

---

## ⚠️ 자주 발생하는 오류 해결 팁 (학생 안내용)

* **"Cannot resolve symbol 'R' 어쩌고 에러가 나요!"**
  👉 상단 메뉴에서 **`Build` -> `Clean Project`** 후 **`Rebuild Project`**를 차례대로 클릭해 보세요.
* **"Hilt 관련 에러(Kapt 어쩌고)가 납니다."**
  👉 상단에 코끼리 모양 아이콘(**Sync Project with Gradle Files**)을 다시 한 번 눌러 동기화를 맞춰주세요.
* **"코드가 다 빨간 줄이에요!"**
  👉 Gradle Sync가 아직 안 끝났거나, 인터넷 연결 문제로 라이브러리 다운로드가 멈춘 경우입니다. 인터넷 연결을 확인하고 다시 Sync해 보세요.
